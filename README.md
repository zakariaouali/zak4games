# Steam Game Store

A clean, responsive storefront for selling Steam games with a professional hero, live catalog layout, badge filters, and card-based browsing.

## Run locally

1. Start the local server:

```bash
npm run dev
```

2. Open the site at the address shown in the terminal, usually `http://localhost:5173`.

## Catalog data

The storefront proxies the live catalog from Bulk Games through the local API at `/api/games`.
